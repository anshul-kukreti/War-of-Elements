⚔️ War of Elements

A simple and interactive elemental battle game built using HTML, CSS and JavaScript.

🎮 About

Choose an element and battle against the computer. Each element has its own strength and weakness, making every round a quick strategic challenge.

✨ Features

- 🔥 5 elemental choices
- 🤖 Computer opponent
- 🏆 Win, Lose and Draw results
- 📊 Score tracking
- 🎨 Interactive user interface
- 📱 Responsive design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "main.html" in your browser.
